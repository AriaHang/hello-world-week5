DON’T WAKE THE CAT — Final Submission + Sound (based on stable 4.2)

The 4.2 game mechanics and code-drawn character art are retained. Four optional Web Audio sounds were added: footsteps, fridge, Mochi meow on detection, and a short victory melody. All sounds are generated by JavaScript in audio.js; there are no MP3/PNG asset dependencies.

Run index.html using VS Code Live Server. Internet connection needed for p5.js CDN. Browser audio starts only after a key press.

A/D: move | Shift: sneak | E: interact/hide | T: toss treat | N: next night | R: restart | M: mute/unmute.

GitHub: upload all SEVEN files together (index.html, style.css, cat.js, game.js, sketch.js, audio.js, README.txt). Do not upload the ZIP alone.

Recommended smoke test: move right, listen for steps; collect a snack from the fridge (click); bring it back to bed (victory); try M to toggle sound. Browser runtime not guaranteed until you test.
